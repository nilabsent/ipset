### Автоматически обновляемые подсети CDN на основе данных сайта [ripe.net](https://stat.ripe.net)
#

При автообновлении списков используется метод `amend`, который перезаписывает хеш последнего коммита.
Прежде чем вручную что-то изменять в локальном репозитории, его необходимо синхронизировать с репозиторием на GitHub:

```
git fetch origin && git reset --hard origin/main
```
